# Bookinfy

MVP visual de uma plataforma de agendamento e gestão para barbearias, salões e negócios de cuidado. Construído com Next.js, TypeScript e Tailwind CSS.

Inclui site institucional, agendamento online e painéis demonstrativos de dono e funcionário. Os dados são fictícios e ficam no navegador; API em Go e automações pertencem às próximas etapas.

```sh
npm ci
npm run dev
```

Requer Node.js 22.18 ou superior. Abra `http://127.0.0.1:3000`. Use “Explorar como dono(a)” ou “Explorar como funcionário(a)” em `/login`.

A documentação completa fica exclusivamente no [vault bookinfy-obsidian](../bookinfy-obsidian/Bookinfy.md). Leia [AGENTS.md](./AGENTS.md) antes de alterar o projeto.
