# Bookinfy

Plataforma de agendamento para barbearias, salões e negócios de cuidado. O frontend usa Next.js, TypeScript e Tailwind CSS. A Etapa 2 conecta o agendamento e a agenda do dono a uma API em Go e PostgreSQL.

```sh
npm ci
npm run dev
```

Requer Node.js 22.18 ou superior. Abra `http://127.0.0.1:3000`. Sem configuração adicional, o frontend abre a demonstração com dados fictícios.

Para usar o fluxo com PostgreSQL, consulte a [execução da Etapa 2](https://github.com/iweti/iweti-obsidian/blob/main/bookinfy/Operacoes/Executar%20etapa%202.md). A documentação do projeto fica no [vault unificado da IWETI](https://github.com/iweti/iweti-obsidian/blob/main/bookinfy/bookinfy.md). Leia [AGENTS.md](./AGENTS.md) antes de alterar o projeto.
